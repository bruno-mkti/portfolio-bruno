# Portfólio | Bruno Silva – Gestor de Tráfego & Estrategista Digital
HTML, CSS e JavaScript puros. Sem build, sem dependências (só a fonte Saira, via Google Fonts).

## 1. Alterar o WhatsApp
`js/script.js`, objeto `CONFIG`: campo `whatsapp` (DDI + DDD + número, só dígitos) e `mensagem`.
## 2. Alterar textos
Tudo está em `index.html`, dividido por seções (hero, sobre, case GWM, experiências, método, habilidades, contato).
## 3. Alterar cores
`css/style.css`, bloco `:root` no topo (`--red` é o destaque, `--bg` o fundo).
## 4. Imagens
Arquivos em `assets/` (logo, favicon, og-image). Para o compartilhamento em redes, use a URL completa do domínio em `og:image`.
## 5. Publicar
Netlify/Vercel (arrastar a pasta), GitHub Pages (Settings → Pages → branch `main`, pasta `/root`) ou hospedagem tradicional (`public_html`).
